CHEF fleet ツールは、Herdr の通常セッションサーバーの上に **何がどこで動いているか**
の任意コンテキストを追加します。Herdr がランタイムの所有者のまま、プラグインと
gateway が中立な位置情報を公開します。

## Fleet Ops Bar

有効にすると、Herdr はペイン境界の下にリンク済みプラグイン由来の fleet コンテキストを
表示します。**設定 → プラグイン**、または config の `ui.fleet_ops_bar = true` で
切り替えます。

バーは `$HERDR_PLUGIN_STATE_DIR/fleet_ops.json` からマージされたプラグイン状態を
読みます。表示専用で、シークレットや Herdr コア状態への書き戻しはありません。

## fleet_ops.json contract

`com.chefgroep.*` プラグインは `$HERDR_PLUGIN_STATE_DIR/fleet_ops.json` に JSON
フラグメントを書き込みます。Herdr はすべての fleet プラグインの断片をマージし、
短い TTL でバーを更新します。

表示して安全な小さな断片に留めてください:

- ホストまたは fleet の要約文字列
- online/total カウント
- 資格情報を含まないリンクやラベル

作業項目の正本は Linear、PR/CI は GitHub、ランタイム健全性はホスト / Cloudflare
API です。API トークンや秘密鍵を `fleet_ops.json` に保存しないでください。

ローカルスキャフォールドのリンクとアクション呼び出し:

```bash
herdr plugin link ./plugins/ops
herdr plugin action invoke publish-context --plugin com.chefgroep.ops
```

## Ops plugins

| 要素 | 役割 |
| --- | --- |
| `com.chefgroep.ops`（リポジトリ内スキャフォールド） | 契約を示し、無料 CI でプラグイン経路を検証 |
| [GroepOnline/herdr-ops](https://github.com/GroepOnline/herdr-ops) | 本番インベントリ、Tailscale/ホストプローブ、SSOT プラグイン |

リポジトリ内スキャフォールドは最小限の host/socket 要約を公開します。本番
インベントリとヘルスチェックは `herdr-ops` に置き、他の Herdr プラグインと同様に
リンクまたはインストールしてください。

マニフェスト項目とアクション配線は[プラグイン](/ja/docs/plugins/#chef-fleet-プラグインプレビュー)を参照。

## Host identity

複数マシンで Herdr を動かすときは安定したホストラベルを設定します:

```bash
export HERDR_HOST_NAME=build-01
```

`HERDR_HOST_NAME` が未設定のとき、Herdr・fleet プラグイン・gateway は `HOSTNAME`
または OS ホスト名にフォールバックします。fleet 全体で一意の値を推奨します。

## herdr-gateway

`herdr-gateway` はローカル Herdr ソケットの前段の小さな HTTP アダプタです。
ソケット API の代替ではなく、スクリプト・fleet ツール・Moshi 系クライアント向けの
読み取り専用 JSON ルートを公開します。

Herdr サーバーがすでに動いているホストで実行:

```bash
herdr-gateway
# 既定 http://127.0.0.1:7777
```

環境:

| 変数 | デフォルト | 目的 |
| --- | --- | --- |
| `HERDR_GATEWAY_PORT` | `7777` | TCP 待ち受けポート |
| `HERDR_SOCKET_PATH` | `~/.config/herdr/herdr.sock` | Herdr サーバーソケット |

リモートから使う場合は SSH ポートフォワードまたは Tailscale serve を使います。
gateway は既定で localhost にバインドします。

### HTTP routes

| ルート | 説明 |
| --- | --- |
| `GET /health` | gateway 稼働時間、ソケットパス、ホスト名 |
| `GET /v1/ops/context` | ホスト + ソケット + `agent.list` + `session.snapshot` |
| `GET /v1/agents` | `agent.list` へのプロキシ |
| `GET /v1/workspaces` | `workspace.list` へのプロキシ |
| `GET /v1/session` | `session.snapshot` へのプロキシ |
| `GET /v1/events` | `events.subscribe` からの SSE |

例:

```bash
curl -s http://127.0.0.1:7777/v1/ops/context | jq .
```

`/v1/ops/context` は中立な **ランタイム位置** 面です。`herdr-ops` のインベントリ
SSOT プラグインは、私有 TUI 専用フィールドを追加せず、このエンドポイント（または
ソケット API）を消費してください。

## Mobile and remote attach

iPhone からは、Herdr をホスト上に置いたまま SSH または mosh で接続します。
[Moshi（iPhone）と Herdr](/ja/docs/moshi/) を参照。スマホから接続する前に
`/v1/ops/context` または Fleet Ops Bar で正しいホストを選んでください。
