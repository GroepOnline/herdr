Moshi（[getmoshi.app](https://getmoshi.app)）是面向你已掌控机器上的编码代理的
移动终端。它不是 Kyutai 语音模型，并且本发行版**不使用 Hermes**。

## Recommended setup

1. 在主机上把代理与 shell 放在 Herdr 中（持久 pane / workspace）。
2. 通过 SSH（或 mosh）暴露主机；舰队主机建议用 Tailscale。
3. 在 Moshi 中保存到该主机的连接，并进入对应的 Herdr session / pane
   （或运行 `herdr` / `herdr session attach` 的 shell）。
4. 可选：用 Moshi agent hooks / webhooks 在代理阻塞时推送通知；
   仍由 Herdr 负责服务端多路复用与状态。

## Why Herdr + Moshi

| Concern | Owner |
|---|---|
| Pane persistence, agent state, fleet ops bar | Herdr on the host |
| Phone UI, dictation, push / Live Activities | Moshi |
| Host reachability | SSH / mosh / Tailscale |

Moshi 不能替代 Herdr。把它当作已经运行代理的机器上的远程客户端。

## Fleet tip

多主机在线时，请设置唯一的 `HERDR_HOST_NAME`，并使用网关
`GET /v1/ops/context`，以便在手机接入前看清**何处运行着什么**。
完整 HTTP 面见 [Fleet ops 与 gateway](/zh-cn/docs/fleet-ops/)。
生产库存插件应放在 `GroepOnline/herdr-ops`（`com.chefgroep.ops`）。

网关绑定在 `127.0.0.1`，因此手机无法直接访问 `/v1/ops/context`。请在主机上
查询，或先通过 SSH 转发端口（例如 `ssh -L 7777:127.0.0.1:7777 <host>`），
再经隧道调用该端点。
