CHEF fleet 工具在 Herdr 常规范会话服务器之上增加可选的**何处运行着什么**
上下文。Herdr 仍是运行时所有者;插件与 gateway 向操作者和手机客户端暴露中性的
位置事实。

## Fleet Ops Bar

启用后,Herdr 在窗格边框下方渲染来自已链接插件的 fleet 上下文。在
**设置 → 插件**中切换,或在配置里设置 `ui.fleet_ops_bar = true`。

该栏从 `$HERDR_PLUGIN_STATE_DIR/fleet_ops.json` 读取合并后的插件状态。
仅供展示:不含密钥,也不写回 Herdr 核心状态。

## fleet_ops.json contract

`com.chefgroep.*` 插件向 `$HERDR_PLUGIN_STATE_DIR/fleet_ops.json` 写入 JSON
片段。Herdr 合并所有 fleet 插件的片段,并在短 TTL 内刷新该栏。

片段应小而安全:

- 主机或 fleet 摘要字符串
- online/total 计数
- 不含凭据的链接或标签

工作项以 Linear 为准;PR/CI 以 GitHub 为准;运行时健康以主机 / Cloudflare API
为准。不要在 `fleet_ops.json` 中存储 API 令牌或私钥。

链接本地 scaffold 并调用动作:

```bash
herdr plugin link ./plugins/ops
herdr plugin action invoke publish-context --plugin com.chefgroep.ops
```

## Ops plugins

| 组件 | 作用 |
| --- | --- |
| `com.chefgroep.ops`（仓库内 scaffold） | 说明契约,并在免费 CI 中演练插件路径 |
| [OnlineChefGroep/herdr-ops](https://github.com/OnlineChefGroep/herdr-ops) | 生产库存、Tailscale/主机探测与 SSOT 插件 |

仓库内 scaffold 发布最小的 host/socket 摘要。生产库存与健康检查应放在
`herdr-ops`;与其他 Herdr 插件一样链接或安装即可。

清单字段与动作接线见[插件](/zh-cn/docs/plugins/#chef-fleet-插件预览)。

## Host identity

多台机器运行 Herdr 时,设置稳定的主机标签:

```bash
export HERDR_HOST_NAME=build-01
```

未设置 `HERDR_HOST_NAME` 时,Herdr、fleet 插件与 gateway 会回退到 `HOSTNAME` 或
操作系统主机名。fleet 内请使用唯一值,避免手机接入与 ops 面板混淆不同主机。

## herdr-gateway

`herdr-gateway` 是本地 Herdr socket 前的小型 HTTP 适配器。它不能替代 socket
API;为脚本、fleet 工具与 Moshi 类远程客户端暴露少量只读 JSON 路由。

在 Herdr 服务器已在运行的主机上启动:

```bash
herdr-gateway
# 默认 http://127.0.0.1:7777
```

环境:

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HERDR_GATEWAY_PORT` | `7777` | TCP 监听端口 |
| `HERDR_SOCKET_PATH` | `~/.config/herdr/herdr.sock` | Herdr 服务器 socket |

远程访问请用 SSH 端口转发或 Tailscale serve;gateway 默认绑定 localhost。

### HTTP routes

| 路由 | 说明 |
| --- | --- |
| `GET /health` | gateway 运行时间、socket 路径、主机名 |
| `GET /v1/ops/context` | 主机 + socket + `agent.list` + `session.snapshot` |
| `GET /v1/agents` | 代理到 `agent.list` |
| `GET /v1/workspaces` | 代理到 `workspace.list` |
| `GET /v1/session` | 代理到 `session.snapshot` |
| `GET /v1/events` | 来自 `events.subscribe` 的 SSE |

示例:

```bash
curl -s http://127.0.0.1:7777/v1/ops/context | jq .
```

`/v1/ops/context` 是中立的**运行时位置**面。`herdr-ops` 中的库存 SSOT 插件应
消费此端点(或直接消费 socket API),而不是添加私有 TUI 专用字段。

## Mobile and remote attach

iPhone 接入时,保持 Herdr 在主机上,通过 SSH 或 mosh 连接。见
[Moshi（iPhone）与 Herdr](/zh-cn/docs/moshi/)。从手机连接前,用
`/v1/ops/context` 或 Fleet Ops Bar 选择正确的主机。
